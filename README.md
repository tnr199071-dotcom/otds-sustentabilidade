# O.T.D.S | Sustentabilidade Inteligente
Projeto sustentável baseado nas ODS 2, 9 e 11.

🔗 **Acesse o site:** [otds11.netlify.app](https://otds11.netlify.app/)

## Sobre o projeto

O O.T.D.S é um site desenvolvido para promover a gestão consciente de resíduos orgânicos em ambientes escolares, unindo educação ambiental, compostagem e inovação sustentável. O projeto foi criado para uma apresentação acadêmica, com foco em front-end (layout, UI, cores, responsividade e interatividade).

O site aborda três Objetivos de Desenvolvimento Sustentável (ODS) da ONU:

- **ODS 11** — Cidades e Comunidades Sustentáveis (foco principal)
- **ODS 2** — Fome Zero e Agricultura Sustentável
- **ODS 9** — Indústria, Inovação e Infraestrutura

## Funcionalidades

- Página institucional com navegação por seções (Home, Projeto, ODS, Interação, Referências, Contato)
- Elemento interativo de "lixeira inteligente", com nível de reciclagem que reage a cliques
- Seção de referências com iniciativas reais de sustentabilidade e compostagem
- Layout responsivo, adaptado para diferentes tamanhos de tela

## Tecnologias utilizadas

- **HTML5** — estrutura das páginas
- **CSS3** — estilização, layout, cores e responsividade
- **JavaScript** — interações e funcionalidades do site
- **Git & GitHub** — controle de versão e hospedagem do código
- **Netlify** — deploy e hospedagem do site
- Desenvolvido com **VS Code** e **Live Server** para testes locais
